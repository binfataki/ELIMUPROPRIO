# ELIMU — Portail propriétaire

Dépôt autonome du tableau propriétaire ELIMU.

Le portail s’ouvre directement depuis `index.html`, utilise son propre dossier `assets/` et consulte les données publiées par Apps Script en lecture seule. Aucun code propriétaire n’est demandé dans l’interface.

Le fichier `config.js` contient l’URL Apps Script de l’établissement.
